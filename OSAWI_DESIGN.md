## LAYER 0 & 1: PORTICO + THRESHOLD

- Austerity is authority. No marketing. No stock photos. Just the gate.
- Hero: `APT-LABS · LEDGER 1.254 · KIRINYAGA, KENYA`, Search + Login top-right.
- `# We're making a list. / Of everyone in Kirinyaga who can actually do things. / That's the whole company.`
- Buttons: [ See the List ] [ Get On the List ]. Either forces single-field phone prompt (`+254 ______`). One SMS OTP. No passwords. Phone = physical anchor to the grid.

## LAYER 2: BENBEN (Outer Courtyard)

- Primordial mound. Communal campfire where unsealed and initiated share air.
- Medium: monospace, obsidian, stark text. Zero images, zero emojis, zero corporate design.
- Rules: read & comment for anyone with OTP (discussions, code debug, local telemetry). No vote, no write, no jobs board, no archives.
- Live ticker at bottom: `* @Josphat sealed hash a3f9 (Mwea) * Node 1.254 verified *`

## LAYER 3: THE SEAL (100 KES Paybill)

1. Gap Test: three first-principles questions (spatial, logical, physical friction).
2. Hash generation: cryptographic capability hash + portable Hash Card (business card + CV + voter ID).
3. Cloaked toll: *"Your hash exists in volatile memory. To permanently seal your node into the Kirinyaga Ledger, send 100 KES to Paybill 123456. Account: your handle."*
- Why: they built the hash themselves; 100 KES turns temporary thought into permanent stone.

## LAYER 4: THE CRUCIBLE (The Sort)

- Three questions. Zero memorization. Pure friction.
- 5 tiers (material progression):
  1. **Sand (0–39%)** — unformed. Returned to BenBen. Retry in 30 days.
  2. **Clay (40–59%)** — moldable. Returned to BenBen. Retry in 14 days.
  3. **Stone (60–79%)** — set and reliable. Unlocks ledger write + jobs board.
  4. **Crystal (80–94%)** — sharp. Unlocks ledger + invitation to one hall.
  5. **Diamond (95–100%)** — sovereign. Unlocks ledger + all 8 halls.

## DUAL ENGINE: INSTITUTIONAL CORE (KemetOS CatalytIQ Apt-labs)

- Schools don't buy software — they buy operational sovereignty. **100,000 KES/year** master anchor unlocks everything for teachers + students. Zero individual teacher fees.

### School dashboard (principal admin)
- SMIS + roster control: free bulk student add via admission numbers; classes/streams/department mapping.
- Library management + borrowing linked to student hashes.
- Science-based lesson planning + timetable engine (cognitive retention cycles, not bureaucratic habit).
- Institutional task board (macro-tasks to the network).

### Teacher console (free under subscribed school)
- Pre-built evidence-based lesson plans (burnout relief).
- Link-drop assignments (WhatsApp/SMS/classroom) with auto-marking + weakness mapping (holiday catch-up critical).
- Advanced creation tasks: mark past papers, design animations, VR lab concepts.

### Flow
```
[ SCHOOL PAYS 100K/YR ] → SMIS + library → all students free → ALL teachers full access
  → zero teacher paywalls → auto planning/scheduling → link-drop + auto-mark → weakness analytics
```

### Academy console view
`APT-LABS · INSTITUTIONAL NODE · School: Mwea High (340 days left) · Teachers 24 · Students 890 · Tasks 12` → [ SMIS ] [ Assistant ] [ Task Board ] [ Library ]. Text-only clarity. Zero decorative noise.

## DISCOVERY: PAINS, NICHE, PARASITE (field notes)

- **Parents:** no visibility → daily WhatsApp digest 6PM/30s (free if school on platform, else 100/mo). Hook. Viral loop pressures schools.
- **Teachers:** drowning → link-drop + auto-mark (free if school, else 500/mo). Lock. Can't go back.
- **Schools:** fear → auto reports/records/fees, one-click inspection mode. 60k/100k/180k/yr. Host. Anchor.
- **Government:** blind → real-time dashboard (contract, or free for data). Lever. Staged.
- **Youth:** invisible → task board + hashed proof. Free to join, 100 to seal. Output.
- **BenBen community:** free text-only fire (nightly problems, jobs ticker). Pull.
- **Halls:** elite prize. **Paw:** meta, not for sale.
- Parasite economics: feeds on subscriptions + credits + contracts + anonymized data licensing; gives back peace/time/compliance/data/income/stability. Lock = relief, not contract. Leaving means losing records, reputation, income, peace, compliance.

## AMENDMENT 9 — BENBEN v3: HALL 0 (binding, supersedes 4/6/7/8 where they conflict)

**Identity: NO ANON.** Signup = phone OTP, then the user sets a username or takes the yard's suggestion (`Mgeni_4821`-style defaults). Phones are checked at the door and **never rendered anywhere** — no public directory, no bulk surface, WhatsApp revealed only to accepted requesters. `robots.txt` bars crawlers from everything but `/` and `/contact`. Server stage adds real rate limits; nothing faked meanwhile.

**The ladder (localStorage now):**
- **Visitor (free):** read everything, comment, post 72h builds. No vote.
- **Certified — KES 50, no test:** voting, 7-day posts, silent hall nominations, downloadable canvas certificate (obsidian, gold, 12-cell geometry, Playfair name, mono hash, *"Carried, not crowned."*).
- **Hall — KES 100 + 8Q exam:** pass 5/8 → tiers → **one hall**; claim Zep-Tepi tasks; bank-facing weight. Fail → playground, Sand 30d / Clay 14d, retest costs 100 again.

**BenBen = the floor.** Every post is a build: 12 domains × 5 types (NEED/OFFER/SOLUTION/FAILURE/QUESTION) × needs checklist. Velocity-ranked (`votes6h/hours × recency`), tier weight always 1.0, ties shuffled per load, 3-per-domain-per-20 cap. FORK comments are the only currency. Silent nominations: certified+ nominate to a hall, 3 hall yes-votes invite, poster never sees rejection. Cold Shelf (`/benben/shelf`) searchable, never browsable. Your slot (`/benben/me`): private stats, yearly rename, upgrade CTAs. 8 seed builds set the standard. Routes: `/benben`, `/benben/new`, `/benben/post/[id]`, `/benben/shelf`, `/benben/me`. WhatsApp reveal: request → poster accepts in slot → shown to accepter alone.
