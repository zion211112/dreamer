## TECHNICAL ARCHITECTURE DECISIONS

### Cryptographic Primitives (Hidden, Not Marketing):
- **SBTs (Soulbound Tokens):** Non-transferable reputation/identity
- **ZK-SNARKs/STARKs:** Private credentials, selective disclosure
- **Merkle DAGs:** Local-first record sync (IPFS/Ceramic-like)
- **Threshold Cryptography:** Distributed key management for DAOs
- **VRFs:** Fair randomness for allocation lotteries
- **Homomorphic Encryption:** Private tallying for voting

### Infrastructure Choices:
- **Hosting:** African data centers only (no AWS/Azure/GCP dependency)
- **Compute:** Kubernetes on bare metal (K3s/RKE2), eventually custom OS
- **Networking:** Mesh overlay (libp2p/Yggdrasil) for sovereignty
- **Storage:** IPFS/Filecoin + local replication
- **Identity:** DID:key + SBT (ERC-5114/ERC-6551 compatible)
- **Payments:** Interledger + African CBDCs + Bitcoin Lightning (optional)
