# Free Resources for APT-LABS Site

## Visualization & Diagrams
- [React Flow](https://reactflow.dev/) - Interactive node-based graphs (perfect for the loop diagram)
- [Excalidraw](https://excalidraw.com/) - Free hand-drawn diagrams, export SVG
- [Mermaid Live Editor](https://mermaid.live/) - Generate diagrams from text
- [Lucidchart Free](https://www.lucidchart.com/pages/) - Flow diagrams
- [SVG Repo](https://www.svgrepo.com/) - Free SVG icons, no attribution
- [Heroicons](https://heroicons.com/) - Tailwind's icon set (MIT)
- [Phosphor Icons](https://phosphoricons.com/) - Clean, consistent icons

## Performance & Analysis
- [PageSpeed Insights](https://pagespeed.web.dev/) - Google's real user + lab metrics
- [WebPageTest](https://www.webpagetest.org/) - Deep performance analysis, free
- [GTmetrix](https://gtmetrix.com/) - Performance + Core Web Vitals
- [Lighthouse CI](https://github.com/GoogleChrome/lighthouse-ci) - Automated checks
- [Chrome DevTools](https://developer.chrome.com/docs/devtools/) - Local profiling

## Design & Typography
- [Google Fonts](https://fonts.google.com/) - Free web fonts, variable fonts
- [Fontsource](https://fontsource.org/) - Self-hosted fonts, better privacy/perf
- [Utopia](https://utopia.fyi/) - Fluid type scales & spacing
- [Coolors](https://coolors.co/) - Palette generator, accessible contrast
- [Colorable](https://colorable.jxnblk.com/) - Contrast checker
- [Conic CSS](https://www.conic.style/) - Reference for color
- [Radix UI Colors](https://www.radix-ui.com/colors) - Scalable color system
- [OKLCH Color Picker](https://oklch.com/) - Modern perceptual colors

## UX & Accessibility
- [WebAIM](https://webaim.org/) - WCAG guidelines & checker
- [axe DevTools](https://www.deque.com/axe/devtools/) - Accessibility testing
- [Contrast Ratio](https://contrast-ratio.com/) - Quick contrast checks
- [Lighthouse Accessibility](https://web.dev/accessibility-scoring/)
- [NNGroup](https://www.nngroup.com/) - UX research (free articles)
- [Laws of UX](https://lawsofux.com/) - UX principles
- [Refactoring UI](https://www.refactoringui.com/) - Free tips (some paid)

## Code Quality & DevTools
- [Can I Use](https://caniuse.com/) - Browser support
- [Bundlephobia](https://bundlephobia.com/) - Bundle size impact
- [Unpkg](https://unpkg.com/) - CDN for packages
- [jsDelivr](https://www.jsdelivr.com/) - Free CDN
- [Squoosh](https://squoosh.app/) - Image optimization, webp/avif
- [SVGOMG](https://jakearchibald.github.io/svgomg/) - SVG optimization
- [Pagefind](https://pagefind.app/) - Static search (free)

## Inspiration
- [Linear](https://linear.app/) - Reference for crisp, minimal UI
- [V0](https://v0.dev/) - Component ideas (free tier)
- [Raycast](https://www.raycast.com/) - Polished interface patterns
- [Monograph](https://monograph.com/) - Typography-first sites
- [Pika](https://pika.page/) - Beautiful docs/sites

**Why:** These are free, high-quality resources that help achieve "10/10" without cost.

**How to apply:** Use React Flow for the loop diagram (matches task1.txt), optimize images with Squoosh, use Utopia for fluid scales, test with PageSpeed Insights/Lighthouse.
