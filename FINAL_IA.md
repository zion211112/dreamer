1. **VERIFIED** — Citable evidence path exists
2. **PROTOTYPE** — Built, running locally, inspectable; not deployed/sold
3. **TARGET** — Named intended outcome with date/measure; never a measurement
4. **PLANNED** — Designed, not built; no figures/dates
5. **UNKNOWN** — Value not established; rendered explicitly, never omitted
