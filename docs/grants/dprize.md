# Funder: D-Prize

- **Eligibility/status:** D-Prize competitions distribute qualifying proven interventions; the current challenge and intervention must be checked at application time. A generic APT-LABS hardware pitch is not eligible by itself.
- **Leading APT-LABS face:** APT Deploy, only as possible distribution infrastructure for a qualifying proven intervention.
- **Secondary face:** The Roll
- **Evidence required:** A named qualifying intervention, evidence that it is proven, a last-mile distribution method, cost-effective reach method, and distribution outcome measure.
- **Current evidence available:** None recorded for a qualifying D-Prize intervention. APT Deploy is a prototype and is not presented as a proven intervention.
- **Missing evidence:** Challenge/intervention match, intervention evidence, distribution partner, delivery cost, reach data, and outcome method.
- **Claims prohibited:** Presenting APT Deploy, APT Fab, or the Roll as a qualifying proven intervention without the call’s required evidence.
- **Relevant route(s):** `/deploy`, `/evidence`, `/about`
- **Application thesis:** No application thesis is activated yet. Re-open this lens only when a qualifying proven intervention and current challenge match the distribution model.
