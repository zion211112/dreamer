# Grant Lens Policy

Each file in `docs/grants/` is a conditional lens over one APT-LABS system. It is not a separate company identity and is not an application by itself.

A lens is valid only when:

1. the funder’s current call and geography are checked;
2. the leading face matches the call’s actual problem;
3. every available claim is supported by `docs/EVIDENCE-PACK.md`;
4. missing evidence is named rather than hidden;
5. prohibited claims are explicit;
6. D-Prize requires a qualifying proven intervention and GCA requires a matching open call.

Do not copy a generic hardware, education, or “social impact” pitch into a funder file. If the match is weak, the correct thesis is inactive.
