# ADR B2 — Main/Branch prohibition

**Status:** Active  
**Date:** 2026-11-10  
**Scope:** Shell navigation

## Decision

No Main/Branch workspace modes. A branch is a change-set or proposed state, not a separate workspace.

## Rationale

A branch should not be treated as a separate workspace mode in the shell.

## Details

- The fork glyph (└─) may remain as an identity element in proposed-state contexts only.
