## Component reuse and gap analysis

**Reuse now:** Angular shell/navigation; ontology family/relationship/evidence labels; `CoordinationService` read/write seam; relationship graph; inspector; command palette; existing typed domain functions; PostgreSQL/Better Auth/Drizzle prototype infrastructure. Do not add a parallel React/Preact frontend, auth system, database, or generic workflow engine.

**Add only as part of a specific flow:** a reusable record header (stable ID/type/status/scope), activity/provenance list, source/evidence item, permission explanation, explicit action confirmation, accessible filter/search controls, and consistent loading/error/empty/offline states. These should consume shared API contracts and shared auth context rather than maintain local business logic.

**Observed source-level defects/gaps:** the Inspector close action is still a no-op; Records has no detail route; capability claims, Intelligence, and some overview copy remain local or reference-only; there are no attachments, deadlines, notifications, or payments. These are code observations, not a complete runtime/UI audit.
